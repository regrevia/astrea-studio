## 一、这是什么片子

**不是版画，不是快剪。** 是「**横屏 16:9 静态知识幻灯片 + 口播 + 底部字幕条**」的科普讲解片，
22 个镜头，中位停留 **8.6 秒**，零个 3 秒以内的快剪。每屏讲透一个点，然后换屏。

抖音页面标注「内容由 AI 生成」，说明这套版式本身可批量生产。

**要素规格：**

- **背景**：浅灰白 `#F5F6F8`～`#F8F9FA`，中心极弱径向渐变；部分页用浅米色
- **字体**：无衬线（苹方/思源黑体）
- **主标题**：黑 `#1A1F36`，约 80–90pt；关键词用亮蓝 `#2B6BFF` 或橙红提亮
- **蓝字小标**：主标题上方，约 24pt，`#2B6BFF`
- **右上角页码**：灰色 `#8C92A4`，如 `01 / 面试现场`
- **字幕条**：`#1A1F36` 圆角矩形（半径 8–12px），白字，约 28–32pt，底部居中
- **进度条**：底部细线，已播蓝 / 未播灰

**配色语义（固定映射，这是关键）：**

| 颜色 | 含义 | 用在 |
|---|---|---|
| 蓝 `#2B6BFF` | 历史/索引/正确做法 | K、导航、方案、箭头 |
| 绿 | 内容/收益/解法 | V、吞吐加速、优化方案 |
| 橙 | 当前处理/压力 | tn、占用增长、问题框 |
| 红 | 提问/警告 | Q、显存墙 OOM、一次性 |

**开场钩子公式（前 40 秒，逐字稿实证）：**

1. `00:00` 直接把面试官问题甩出来：「面试官问你，大模型推理里天天讲的 KV Cache 到底是什么？」
2. `00:03` 追加矛盾：「为什么只缓存 K 和 V，偏偏不把 Q 一起存下来？」
3. `00:06` 给出**错误答案**：「如果你回答因为 Q 比较大吧……」
4. `00:10` 用羞辱制造张力：「恭喜你，出门右拐回家等通知吧！」
5. `00:12` 短促设问：「为什么？」（1 秒，节奏断点）
6. `00:13`–`00:23` 快速给正确答案（10 秒内讲完核心逻辑）
7. `00:26` 资料钩子（送学习路线 + 288 道八股，评论区扣 R2）
8. `00:39` 三条预告：「什么是 KV Cache？为什么没它会卡死？为什么只存 K/V？」

**可复用模板**：`错误答案羞辱 → 为什么？ → 10 秒正解 → 资料钩子 → 三条预告 → 正片`

结论：**慢节奏、长停留**。每屏 = 一个完整论点，讲完才切。切点密度在 02/03 章最密（40–50 秒内 5–7 个切点），因为那是核心原理拆解。

## 六、视觉表现的三个手法

1. **几何示意图为主**（约 70%）：圆角矩形 + 箭头 + 彩色小方块，画 Q/K/V 向量、Token 序列、显存框
2. **类比卡片**（1–2 处）：图书馆借书（纸条 Q / 索引 K / 书 V）—— 把抽象概念映射到日常
3. **手绘信息图 + 卡通讲师**（1 处，04 章）：橙红表压力，绿蓝表解法，右侧讲师手指图表 —— 全片最"重"的一屏，用在需要情绪转折的地方

## 七、复刻成自动化流水线的最小可行方案

**输入**：一个技术选题（如「什么是 MoE」）

**流程**：

1. **文案**：LLM 按五段式生成逐字稿，控制 396 字/分钟 × 目标时长
   - 3:30 片 ≈ 1400 字
   - 每句切成 ≤14 字一条字幕（对齐中位 11 字）
2. **配音**：剪映 SAMI `sami:BV411_streaming`（解说小帅）—— 已是工程主力
3. **分镜**：每屏 = 一个论点，按 3–8s（讲点）/ 8–23s（讲透）配时长
4. **画面**：HTML/CSS 模板渲染成 1920×1080 PNG
   - 固定三段版式（导航 / 主图 / 字幕条）
   - 配色按上表语义映射
   - 主图用 SVG 画几何示意图（不用图像模型，可控且快）
5. **合成**：ffmpeg 把 PNG 序列 + 音频 + 字幕烧成 MP4（30fps）
6. **发布**：手动（当前边界）

**不需要**：视频生成模型、逐图版画风格、AI 绘图。
这套版式的成本几乎全在**文案质量**和**分镜逻辑**，画面是 CSS 渲染，秒级出图。
