# 阿斯特立绘清单（交给生成方）

管线现状：`integrations/mac-worker/character.py` 是程序化占位图，参数只有三个：
`pose`（idle / wave / point / think / shrug / happy）、`mouth`（closed / half / open / round）、
`eyes`（open / closed）。真图到位后我加一层「按文件名取图」的加载器，所以**文件名必须严格照下表**，
不要加空格、不要中文名。

结论：**要 12 张**（最少 7 张也能先跑）。同一套角色设定，先出 1 张主图，其余全部拿主图做
「局部重绘」，不要文字重抽——重抽就会换脸。

## 0. 共用角色设定（每张都原样粘，一个字都不要改）

```
角色设定：蓝发鲸鱼娘「阿斯特」，2.5 头身 chibi 少女，深海蓝到浅海的渐变长发，头侧有一对鲸鱼尾鳍形状的发饰，胸前挂一只小小的蓝鲸玩偶，穿白底深蓝滚边的水手连衣裙，裙摆和袖口有鲸鱼尾刺绣，身后一条半透明的蓝色鲸鱼尾巴，眼睛是大而圆的深海蓝，日系赛璐璐上色，清晰描边，柔和高光，平涂阴影。
画布：2048x2048 正方形，纯绿色 #00FF00 纯色背景，无渐变、无阴影、无地面。
构图：全身站姿，脚底踩在画布底部 y=1900 的水平线上，头顶留约 180 像素空白，左右留白对称，角色高度约占画布 80%。
光线：左上 45 度主光，正面补光，人物不向背景投影。
负面：不要阴影投到背景，不要绿色服饰或绿色配件，不要复杂背景，不要文字水印，不要多余角色，不要写实风格，不要 3D 渲染感，不要肢体变形，不要六根手指。
```

**为什么绿幕**：出图工具给不出真透明通道，白底又会和白裙子糊在一起，所以统一绿幕，
我这边色键抠像 + 去溢色变透明。

## 3. 每张的验收（不合格就重抽，别凑合）

- 画布正好 2048×2048，背景纯 #00FF00，没有渐变/地面/投影
- 角色高度占 78%–82%，脚底都在 y≈1900（差分能直接叠）
- 和 01 叠成 50% 透明：除了该改的部位，头发丝、裙摆、手的轮廓要完全重合
- 身上没有任何绿色（反光、眼影、刺绣都不行），否则抠像会被打洞
- 手指数量正确，脸没变形，眼睛高光位置一致
- 没有文字、水印、多余角色、地台
