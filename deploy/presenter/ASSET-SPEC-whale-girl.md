# 鲸鱼娘资产规格与出图提示词（GPT-image-2）

> 用途：为 Astrea Studio 的"主角模块"生成一套可程序驱动口型的 2D 差分立绘。
> 生成方：你（GPT-image-2 / ChatGPT 画图）。
> 消费方：`integrations/mac-worker/` 的 presenter 渲染管线（透明 PNG 差分 + 音频 RMS 切帧）。

---

## 0. 一句话角色设定（所有 prompt 共用，保证一致性）

> 蓝发鲸鱼娘「阿斯特」：2.5 头身 chibi 少女，深海蓝到浅海的渐变长发，头侧有一对鲸鱼尾鳍形状的发饰，胸前挂一只小小的蓝鲸玩偶，穿白底深蓝滚边的水手连衣裙，裙摆和袖口有鲸鱼尾刺绣，身后一条半透明的蓝色鲸鱼尾巴，眼睛是大而圆的深海蓝，日系赛璐璐上色 + 清晰描边，柔和高光，无背景装饰。

**这套设定请固定成一段文字，每次生成都原样粘进 prompt，不要改写措辞**——改一个字，模型就会换一次画风。

---

## 1. 生成流程（很重要，决定成败）

1. **先只生成主图（#01）**，反复重抽直到满意。这张是整套资产的美术基准。
2. 之后**全部用"图片编辑/局部重绘"模式**，把 #01 作为输入图，只改嘴、眼睛或姿势。
   - 纯文字重新生成 = 换脸，不能用。
   - 编辑时务必在 prompt 里写：`保持原图的人物、发型、服装、配色、光线、构图、大小和位置完全不变，只修改嘴部`。
3. 每生成一张，先核对第 6 节的验收清单，不合格就重抽，不要凑合——差分对不齐，后期口型就会"跳脸"。

---

## 2. 技术规格（所有图统一）

| 项 | 要求 |
|---|---|
| 画布 | **2048 × 2048**，正方形 |
| 背景 | **纯绿色 #00FF00 平涂**，无渐变、无阴影、无地面。人物身上不能出现绿色（本角色配色不含绿，安全） |
| 构图 | 全身站姿，**脚底踩在画布底部 y≈1900 的水平线上**，头顶留 ~180px，左右留白对称 |
| 角色高度 | 约画布高度的 78%–82% |
| 朝向 | 正面（除 #09/#10 两张"看向侧面"） |
| 光线 | 左上 45° 主光，正面补光，**不要投影到背景上** |
| 描边 | 均匀外描边，线宽相当于角色高度的 0.5% |
| 格式 | PNG，不要 JPEG（压缩花纹会毁掉抠像边缘） |

**为什么用绿幕**：GPT-image-2 出不了真透明通道；我们用色键抠像（`Pillow` + 去溢色）把它变透明。白底会和她的白裙子、白蕾丝、白袜子糊在一起，所以必须绿幕。

## 6. 验收清单（每张都过一遍）

- [ ] 画布正好 2048×2048，背景是纯 #00FF00，没有渐变/地面/阴影
- [ ] 角色高度占画布 78%–82%，脚底在同一条水平线上（差分之间**能直接叠图对齐**）
- [ ] 与 #01 叠在一起看，除了该改的部位，其余轮廓完全重合（头发丝、裙摆、手的位置都不能飘）
- [ ] 身上没有绿色（包括反光、眼影、刺绣），否则抠像会被打洞
- [ ] 没有文字、水印、额外角色、地台
- [ ] 手指数量正确，脸部没有变形
- [ ] 眼睛高光位置一致（差分切换时不能"高光跳位"）

> 快速自检方法：把两张图在画图软件里叠成一层、透明度 50%，轮廓不重影才算合格。

## 7. 交付后我们做什么（你不需要管）

1. 绿幕抠像 → 透明 PNG（含去溢色，避免边缘泛绿）
2. 按音频逐帧算 RMS 能量 → 在 `closed / half / open / round` 四态之间切帧（带 40ms 消抖，避免抖动抽搐）
3. 眨眼按 3–6 秒随机触发，一次 120ms
4. 姿势切换跟分镜脚本绑定（讲解段用手势、提问段用思考、反转用惊讶）
5. 全部合成进现有透明 WebM overlay，24fps，与配音严格对齐
