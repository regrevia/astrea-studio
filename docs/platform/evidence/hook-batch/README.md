# 三段钩子 + 批量轮换钩子文案

一条 30 秒的片子拆成三段：0–10 s 抛问题、10–20 s 给卖点、20–30 s 给行动。工作区里三段各一行，
**开场那一行可以写多个钩子，用「｜」隔开**——点「出 3 版」时后端逐条轮换开场文案，画面、拍点、标题都不动。

## 走的路

1. 工作区「片子素材」卡：标题「一杯好咖啡」、副标题「现磨直送」。
2. 开场填「还在排队买咖啡？｜咖啡凉了才到家」，中段「三分钟送到家」，收尾「点下方领 20 元券」。
3. 选 3 条素材、配乐 `demo-120.m4a`，点「出 3 版」。

排片函数把文字层排成 5 行：标题 `y 0.2`（0.3–29.6 s）、副标题 `y 0.29`（0.9–29.5 s）、
三段钩子 `y 0.66`（0.2–9.85 / 10.2–19.85 / 20.2–29.5 s），各留 0.2 s 呼吸。
第一段钩子行带 `hookVariants`，批量时按第几条取第几个。

## 顺手修的两件事

- `varyHook` 原来固定换 `text[0]`，标题占第一位就换错行了；改成按 `hookVariants` 找那一行。
- `video_qa` 的字幕取样带原来把所有文字行的 `y` 取平均，标题 0.2 与钩子 0.66 平均到 0.49——那一带本来没字，
  于是三条片子都报了假 `text_gap`。现在按在屏时间最长的那一行取带，三条重新全绿，并补了单测。
