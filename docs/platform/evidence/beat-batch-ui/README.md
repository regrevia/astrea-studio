# 工作区点「出 3 版」批量出片

素材、配乐、卡点、标题都在网页工作区里定好，点一下「出 3 版」，后端一次入队三条，各自渲染落库。
这是「后期批量生成」在界面上的入口，前一条证据走的是接口，这条走的是按钮。

## 走的路

1. 工作区「片子素材」卡：填标题「一杯好咖啡」、副标题「三分钟送到家」。
2. 选 3 条真实素材，配乐选 `demo-120.m4a`，「按鼓点切」保持勾选。
3. 点「出 3 版」→ `POST /api/production/runs/batch`（`count: 3`，同一份排布）。
4. 三条串行渲染，各自落库，任务面板一次出现 3 条。
