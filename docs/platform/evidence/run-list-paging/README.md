# 制作台任务列表能往下翻了

## 之前的问题

制作台一次只拉最新 30 条，项目下拉框是在这 30 条里过滤，所以项目里攒到几百条以后，
早先的片子在这个页面上永远翻不到，只能进项目工作台找。

## 现在

选了项目就按项目取，列表底部给「加载更多（还有 N 条）」，翻过的页在轮询刷新时一次拉回来，不会被刷回去；
换项目从第一页重新开始。

## 验的东西

在浏览器里选项目「envoy 剪映原生演示」（544 条任务）：

- 翻之前：「加载更多（还有 514 条）」。
- 点一次之后：「加载更多（还有 484 条）」。

差值正好 30 条，说明续上的是一整页真实任务。截图 `ui-run-paging.png`。

## 复现

```bash
node /tmp/run-paging.mjs "envoy 剪映原生演示"
```
